# ESP32 互動接線圖 / Interactive Wiring Demo

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是一個靜態網頁，用來互動查看 ESP32 專案接線圖：3D 開發板與麵包板、逐步接線、腳位表和參考程式碼。

**線上觀看：** https://ian2238.github.io/ESP32/

目前包含的專案：

- 蒙娜麗莎（TFT 播放器）
- s3-climate（溫濕度／土壤）
- CAM + OLED

本機預覽：用瀏覽器打開 `index.html`，或在此目錄開一個靜態伺服器。

原始說明見 [README_zh-TW.md](README_zh-TW.md)。

## English

A static site for interactive ESP32 wiring diagrams: 3D board and breadboard, step-by-step wiring, pin tables, and sample code.

**Live site:** https://ian2238.github.io/ESP32/

Projects included:

- Mona Lisa (TFT player)
- s3-climate (temperature / humidity / soil)
- CAM + OLED

To preview locally, open `index.html` in a browser or serve this folder with a static file server.

See [README_zh-TW.md](README_zh-TW.md) for the original notes.
